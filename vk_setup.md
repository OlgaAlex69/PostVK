# Как подключить проект к сообществу ВКонтакте

Простая инструкция для новичков. Всё займёт 5-10 минут.

---

## Что нужно сделать (кратко)

1. Создать или войти в сообщество ВКонтакте
2. Создать приложение ВКонтакте (это даст доступ к API)
3. Получить токен доступа (ключ)
4. Узнать ID сообщества
5. Вставить эти данные в файл `app.py`

---

## Шаг 1: Подготовьте сообщество

Если у вас уже есть сообщество ВКонтакте, переходите к Шагу 2.

Если нет:
1. Зайдите ВКонтакте
2. В левом меню нажмите «Сообщества» → «Создать сообщество»
3. Выберите тип (например, «Бизнес»)
4. Заполните название и описание
5. Сохраните

---

## Шаг 2: Создайте приложение ВКонтакте

Это нужно, чтобы получить ключ доступа к API.

1. Перейдите по ссылке: **https://vk.com/apps?act=manage**
2. Нажмите кнопку **«Создать приложение»**
3. Введите любое название, например: `Post Generator`
4. Выберите тип: **Standalone-приложение** (это важно!)
5. Нажмите **«Подключить приложение»**

---

## Шаг 3: Получите токен доступа

Самый простой способ — через специальную ссылку.

1. Скопируйте эту ссылку и вставьте в браузер:

```
https://oauth.vk.com/authorize?client_id=ВАШ_CLIENT_ID&scope=wall,offline&redirect_uri=https://oauth.vk.com/blank.html&display=page&response_type=token
```

2. Замените `ВАШ_CLIENT_ID` на ID вашего приложения:
   - Зайдите на **https://vk.com/apps?act=manage**
   - Нажмите на ваше приложение
   - В адресной строке будет цифра после `apps?act=manage&id=` — это и есть Client ID
   - Например, если адрес `https://vk.com/apps?act=manage&id=12345678`, то Client ID = `12345678`

3. После замены откройте ссылку в браузере
4. Разрешите приложению доступ (нажмите «Разрешить»)
5. После этого вы попадёте на пустую страницу — это нормально
6. В адресной строке будет что-то вроде:
   ```
   https://oauth.vk.com/blank.html#access_token=abc123def456&expires_in=0&user_id=12345
   ```
7. Скопируйте значение после `access_token=` и до `&` — это ваш **токен**

**Пример токена:** `vk1.a.Abc123Def456Ghi789Jkl012Mno345Pqr678Stu901Vwx234`

---

## Шаг 4: Узнайте ID сообщества

1. Зайдите в ваше сообщество ВКонтакте
2. Посмотрите на адресную строку
3. Если адрес вида `https://vk.com/club12345678`, то ваш **owner_id** = `-12345678` (со знаком минус!)
4. Если адрес вида `https://vk.com/my_group` (буквенный), то:
   - Откройте страницу сообщества
   - Нажмите на любую запись на стене
   - В адресе будет `wall-12345678_...` — число после `wall-` и есть ваш ID со знаком минус
   - То есть **owner_id** = `-12345678`

**Важно:** owner_id всегда указывается **со знаком минус** для сообществ!

---

## Шаг 5: Вставьте данные в Render Dashboard

> На Render все секреты задаются через **Dashboard → Environment Variables**, а не в `app.py`.

1. Зайдите в Dashboard вашего сервиса на Render
2. Перейдите в **Environment** (вкладка)
3. Добавьте переменные:

| Переменная | Значение | Пример |
|-----------|----------|--------|
| `VK_ACCESS_TOKEN` | Ваш токен ВК | `vk1.a.Abc123...` |
| `VK_OWNER_ID` | ID сообщества | `-12345678` |

4. Нажмите **Save Changes** — сервис автоматически перезапустится

---

### Если запускаете локально

1. Создайте файл `.env` рядом с `app.py`:

```
VK_ACCESS_TOKEN=vk1.a.Abc123Def456Ghi789Jkl012Mno345Pqr678Stu901Vwx234
VK_OWNER_ID=-12345678
```

2. Запустите сервер: `python app.py`

---

## Проверка: работает ли подключение

1. Откройте сайт: **http://127.0.0.1:5000**
2. Сгенерируйте любой пост
3. Нажмите кнопку **«🚀 Опубликовать сейчас»**
4. Зайдите в ваше сообщество ВКонтакте — пост должен появиться на стене

---

## Частые ошибки

### «Не настроены данные ВК»
- Вы забыли вставить токен или owner_id в `app.py`
- Проверьте, что они между кавычками и без лишних пробелов

### «Access token is invalid»
- Токен истёк или неверный
- Получите новый токен через Шаг 3

### «User authorization failed»
- Токен не имеет нужных прав
- Убедитесь, что в ссылке для получения токена есть `scope=wall,offline`

### «Permission to perform this action is denied»
- У приложения нет прав на публикацию в сообществе
- Убедитесь, что вы администратор сообщества
- Попробуйте получить токен заново

---

## Безопасность

- Никому не показывайте ваш токен
- Не выкладывайте файл `app.py` с токеном в интернет
- Токен даёт доступ к вашему сообществу

---

## Итог

Нужно всего 2 значения:

| Параметр | Где взять | Пример |
|----------|-----------|--------|
| `VK_ACCESS_TOKEN` | Через OAuth-ссылку (Шаг 3) | `vk1.a.Abc123...` |
| `VK_OWNER_ID` | Из адреса сообщества (Шаг 4) | `-12345678` |

Вставьте их в `app.py` и готово!
